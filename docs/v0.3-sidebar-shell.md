# v0.3 左侧边栏导航外壳规范（Sider Shell）

| 项 | 说明 |
|---|---|
| 性质 | **定向增量规范**（不改既有视觉体系，只做扩展）；承接 v0.2 §3.1 顶部导航 |
| 上游 | `docs/v0.2-design-system.md`、`docs/v0.3-budget-ia.md`、`src/theme.js`、`src/App.jsx` |
| 下游 | prototype-builder（外壳重建）、critique-reviewer、测试 |
| 硬约束 | 只出规范，不改 `src/`；零硬编码色；新令牌仅追加到 `theme.js` v0.3 扩展区 |

## A. 布局骨架

`<Layout>` = `<Sider>` + `<Layout>`(Header / Content / Footer)。

| 元素 | 值 | 来源 |
|---|---|---|
| Sider 展开宽 | **224px** | 新令牌 `siderWidth` |
| Sider 折叠宽 | **64px**（与 Header 高对齐成方块） | 新令牌 `siderCollapsedWidth` |
| Sider 底色 | **`bg1`（白）** | `token.colorBgContainer` |
| Sider 右边框 | `1px solid split`，**无阴影** | `token.colorSplit` |
| Header 高 | **64px**（不变） | `main.jsx` `Layout.headerHeight:64` |
| Content 内边距 | **16px 24px 32px**（不变） | 现状 |

**底色选择理由（一句话）**：Header 已是 `bg1` 白，Sider 同取 `bg1` 使「Header + Sider」连成同一块白色 chrome，把内容区 `bg2` 灰画布 + 白卡片的**三层材质（chrome / canvas / card）**拉开；选中态 `brandBg` 在白底上可读性最佳。若取 `bg2` 会与页面灰底连成一片，选中底还需再引第三个灰阶。

**Sider 三段结构**：

| 段 | 高 | 内边距 | 内容 |
|---|---|---|---|
| 品牌区 | **64px**，底边 `1px split` | `padding-inline:16px` | 图标 20 `brand` + 标题 13/500 `t1` + 副标 11 `t3`；折叠态仅图标居中 |
| 目录区 | `flex:1`，`overflow-y:auto` | `padding:8px` | 两级目录树（见 B） |
| 折叠触发器 | **48px**，顶边 `1px split` | `padding-inline:16px` | 展开态「« 收起」13 `t2`；折叠态 chevron 居中 |

品牌图标沿用 `ApartmentOutlined`；板块图标新增：预算管理 `WalletOutlined` / 计费账单 `FileTextOutlined` / 项目管理 `ProjectOutlined`。

**断点行为**：

- **≥1200px**：默认展开 224（若 `localStorage` 记录为折叠则折叠）。
- **992–1199px**：强制图标模式 64（用户选择被保留，视口恢复后生效）。
- **<992px**：Sider 退出文档流；点 Header 折叠按钮以左侧 `Drawer`（宽 224、遮罩）唤出。

## B. 目录树项规范（像素级）

**一级（板块）项**

| 项 | 规格 | token |
|---|---|---|
| 高度 | **40px** | 固定 |
| 字号/字重 | **13px / 500** | `t1` |
| 内边距 | `padding-inline:12px` | — |
| 图标 | 16px 前置，`gap:8px` | `t2` |
| 展开箭头 | 10px chevron，右对齐；展开时旋转 90° | `t3` |
| 圆角 | **8px** | `radius` |
| 悬停态 | 底 `navHoverBg` | `colorFillQuaternary` |
| 展开态 | 箭头下指 + 子项展开；label 保持 `t1`/500 |
| 含活动子项 | 一级不额外染色（避免与子项选中抢焦点），**自动展开该组** |

**二级（视图）项**

| 项 | 规格 |
|---|---|
| 高度 | **36px** |
| 字号/字重 | **13px / 400**（选中 → 500） |
| 缩进 | `padding-left:36px`（=12 + 16 图标列 + 8）；`padding-right:12px` |
| 默认色 | `t2` |
| **选中态** | **左 3px `brand` 指示条 + 底 `brandBg` + 文字 `brand`/500** |
| 悬停态 | 底 `navHoverBg` |
| focus-visible | `outline:2px solid brand; outline-offset:-2px` |
| 圆角 | 8px |

**垂直菜单选中态新方案（关键）**：现有 `navActiveIndicator` 是 `2px solid brand` 的**下划线**，只适用横导航；垂直菜单改用 **左侧 3px 品牌色指示条 + `brandBg` 底 + `brand` 文字**（指示条 `position:absolute;left:0;top:0;bottom:0;width:3px`，无需重排内容）。

**新增令牌（写入 `theme.js` v0.3 扩展区，不改任何既有键）**：

```js
/* ============ v0.3 扩展令牌（追加，不改既有键） ============ */
navActiveBar: `3px solid ${token.colorPrimary}`, // 垂直菜单选中项左侧指示条（替代横导航下划线）
siderWidth: 224,          // Sider 展开宽
siderCollapsedWidth: 64,  // Sider 折叠宽（= Header 高）
```

> `navActiveIndicator` 与 `moduleBarBg`（v0.2 横向导航用）本方案**不再引用，但保留不删**（不破坏既有键，符合零改动契约）。

**折叠态（64px）展示规则**

- 品牌区仅 20px logo 居中；目录区仅显示 **3 个一级图标**（20px，行高 44px 居中）。
- 含活动子项的一级图标：icon `brand` + 底 `brandBg` + 左 3px `navActiveBar` → **选中态保留可辨识**。
- hover 一级图标 → `Popover(placement:"rightTop", min-width:180)`；列表为空时用 `Tooltip`，文案来源 = 权威副标题字符串：`${板块名} · ${副标题}`。Popover 内复用二级项视觉（36px / 13px），选中项同款高亮。
- 折叠态点击子视图**正常路由跳转，不自动展开**。

## C. 与 Header / Content 的衔接

**Header（高 64 不变，底色 `bg1`，底边 `1px split`）**

- **左**：折叠触发按钮（icon-only 32×32，icon 16 `t2`，hover 底 `navHoverBg`，圆角 8），`padding-left:16px`。
- **中**：留空（flex spacer）。
- **右**：4 个全局控件，**顺序固定不变**：年度 Segmented → 部门 Select → 全局单号搜索 → ⚙ 设置；`padding-right:24px`。
- 品牌区已移到 Sider，**Header 不再渲染品牌**（`ApartmentOutlined` + 平台名整体下移）。

**Content**

- **取消全量面包屑**（侧边栏已常驻层级，「平台名 ›」纯属重复）。
- **新增内容区顶部轻量定位条**（结论，非两可）：高 **32px**，`margin-bottom:12px`，12px；文案 `板块名 · 副标题 › 视图名`，有对象单号时追加 `› DM-2026-0031`（单号 `brand` 可点击复制）。板块/视图用 `t2`（视图 `t1`/500），副标题 `t3`，分隔符 `›` 用 `t4`。承担 v0.2 §3.1.4「我在哪个板块」的承诺。
- 默认落点改为 `#/budget/annual`；移除「总览」页与 `#/home` 路由。

## D. 可访问性与测试契约

- Sider 根 `<aside>`；树容器 `<nav aria-label="主导航">`。
- 一级 group：`<button aria-expanded={bool} aria-controls="sider-sub-{key}">`。
- 二级项：`<a href="#/budget/annual" aria-current={selected ? 'page' : undefined}>`；键盘 Enter/Space 跳转，↑/↓ 树内移动。
- 折叠触发器：`<button aria-expanded={siderOpen} aria-label="收起导航 / 展开导航">`。
- 持久化：`localStorage['dkt.sider.collapsed'] = 'true' | 'false'`；初始化读取，缺失默认 `false`。

**data-testid 契约（全部）**

| testid | 挂载层 |
|---|---|
| `app-sider` | `<Layout.Sider>` 根，附加 `data-collapsed="true\|false"` |
| `sider-brand` | 品牌区容器 |
| `sider-menu` | 目录区 `<nav>` |
| `sider-collapse` | Header 折叠按钮 |
| `sider-rail-collapse` | Sider 底部折叠触发器 |
| `sider-group-budget` / `-billing` / `-delivery` | 一级 `<button>`（`aria-expanded`） |
| `sider-item-budget-annual` / `-consume` | 二级 `<a>` |
| `sider-item-billing-monthly` / `-reconcile` / `-rules` | 二级 `<a>` |
| `sider-item-delivery-brd` / `-eval` / `-cr` / `-deliver` | 二级 `<a>` |
| `content-locator` | 内容区定位条 |

- 既有视图锚点（`view-delivery-brd` / `budget-annual-table` / `billing-monthly-table` 等）**保持不变**。
- **测试迁移提示**：`tests/smoke.cjs` 第 173–177 行 `.ant-menu-horizontal .ant-menu-item` 断言（=4 项）改为 `[data-testid^="sider-group-"]`（=3 项）；删除「总览」相关断言；`#/home` 断言改为 `#/budget/annual`。

## E. 暗色主题与硬编码红线

- 所有颜色一律 **`useT()`**，Sider 内零 hex。
- 新令牌全部由 `token.colorPrimary / colorBgContainer / colorFillQuaternary / colorSplit / colorPrimaryBg` 派生 → **暗色自动跟随**。
- 唯一注入 CSS：选中项左侧指示条（伪元素 3px，颜色取 `c.navActiveBar` 或 `c.brand`），不含任何色值字面量。
- 唯一既有例外 `#7FA8CC`（`meterCommitted`）与本方案无关，不新增第二处非品牌/非状态色。
- 既有 `navActiveIndicator` / `moduleBarBg` 变为未引用但**不删除**（不破坏既有键）。
