## 5. 遗留问题清单（P0 / P1 / P2）

### P0-1 · ≤1366 视口横向溢出、右侧「版本」列被裁且无法滚动到达
- **现象**：1280 实测「版本」列仅 ~13px 可见；1366 亦被裁（越界约 76px）；页面**无横向滚动条**，内容不可达。1280 下卡片宽 1154 越出视口（right=1403 > innerW=1264）。
- **证据**：Chrome CDP 实测（§3.5），祖链 `Content(min-width:auto)` → 外层 `Layout(sw=1428)` → `Watermark(overflow:hidden)`；`.ant-table-content` `clientW==scrollW==1122`（无内部滚动）→ `fixed:'right'` 失效。截图 `bpplan_1280/1366/1440`。
- **影响**：1366 属需求明确纳入的「内部常见分辨率」；「版本」列是行唯一标识（设计 §D1 的核心论据），被裁即行标识丢失；与设计 §4.2 的预言直接冲突。**高**。
- **建议（精确）**：
  1. `src/App.jsx:246`（内层 `<Layout>`）与 `:297`（`<Content>`）增加 `style={{ minWidth: 0 }}`；或 `src/pages/BudgetModule.jsx:2306` 模块壳外层 `<div>` 加 `minWidth:0`。目的是让 flex 内容区可收缩，使 `Table scroll.x` 产生**内部**横向滚动。
  2. 备选：给表格外层容器（Card / 模块壳 `<div>`）设 `overflow: hidden` 让 `scroll.x` 内部滚动生效。
  3. **验收**：1280/1366 下 `.ant-table-content { clientWidth < scrollWidth }`（出现内部横滚），且版本列 `getBoundingClientRect().right ≤ innerWidth`。

### P1-1 · 同一分钟连续提交 → 新版本未置顶，且主表「当前版本」取错
- **现象**：`D-RETAIL` 在同分钟内连提两版后，列表 `row0=V2.2（补充版2）`、`row1=V2.3（补充版3）`——**最新版未置顶**；因主表当前版本 = `bpVersions[0]`，主表与页面「当前 V.x」也会显示错版本。
- **证据**（独立驱动，两轮均复现）：
  ```
  row0: …（补充版2）…V2.2 2026-09-30 12:xx
  row1: …（补充版3）…V2.3 2026-09-30 12:xx
  ```
- **根因**：`src/domain/calc.js:649` `.sort((a, b) => (a.at < b.at ? 1 : -1))` 对相等 `at` 返回 `-1`（**非法全序**：`cmp(a,b)` 与 `cmp(b,a)` 同为 -1），`at` 精度仅到分钟（`store.jsx` `now = ${TODAY} ${HH:MM}`），同分钟即撞键 → 排序结果不确定。
- **影响**：违反需求「最新版本置顶并即时生效」；误导「当前版本」判定。**中高**（演示中连续两次提交即触发）。
- **建议（精确）**：`calc.js:649` 改为合法全序并加版本号 tiebreak：
  ```js
  .sort((a, b) => {
    if (a.at !== b.at) return a.at < b.at ? 1 : -1;
    const vn = (s) => { const m = /^V(\d+)\.(\d+)$/.exec(s || ''); return m ? Number(m[1]) * 1000 + Number(m[2]) : -1; };
    return vn(b.version) - vn(a.version);
  });
  ```
  并建议 `store.jsx` 的 `now` 提升到秒（`HH:MM:SS`）或加自增 `seq`，从源头消除撞键；同步为 `demandVersionsOf`（同款写法）一并加固。

### P1-2 · 空态引导文案对比度低于 WCAG AA（本页特有）
- **现象/文案/位置**：`未提交` 态主引导「该部门 FY2027 年度 BP 尚未提交 · 点击右上角「修正年度 BP」提交首版」由 `Blank`→antd `Empty` 的 `description` 渲染（`src/components/common.jsx:290`，13px，继承 `colorTextDescription` ≈ `rgba(0,0,0,.45)`）。
- **证据**：`rgba(0,0,0,.45)` 白底 ≈ **3.36:1 < 4.5:1**。这不是「可跳过的元信息」，而是**空态唯一行动引导**。
- **影响**：低视力/强光环境下读不清关键 CTA。**中**。
- **建议（精确）**：`common.jsx:290` 给 `description` 补 `style={{ fontSize: 13, color: useT().t2 }}`（≈7.0:1，AA）；或本页空态改用自定义 `c.t2` 文案块，不改全站 `Blank` 默认。
