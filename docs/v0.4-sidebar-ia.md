# v0.4 侧边栏信息架构变更记录

| 项 | 说明 |
|---|---|
| 性质 | **导航外壳重构**（IA 收口），承接 v0.3 规范 `docs/v0.3-sidebar-shell.md` |
| 上游 | `docs/v0.3-sidebar-shell.md`、`src/theme.js`（v0.3 扩展令牌） |
| 范围 | `src/App.jsx`、`src/components/SiderNav.jsx`（新增）、`src/components/common.jsx`、三个模块页、`tests/smoke.cjs` |

## A. 本轮 IA 变更

1. **删除「总览」页**：`src/pages/Home.jsx` 移除；一级导航由 4 项收敛为 3 项（预算管理 / 计费账单 / 项目管理）。
2. **Header 横向 Menu → 左侧边栏两级目录**：新增手写组件 `SiderNav.jsx`（不用 antd Menu），品牌区从 Header 下移到 Sider，Header 只保留折叠按钮 + 4 个全局控件（年度 Segmented → 部门 Select → 全局单号搜索 → ⚙ 设置，顺序不变）。
3. **ModuleNav 移除**：`common.jsx` 内 `ModuleNav` 定义及三个模块页的调用（预算 / 计费 / 项目）全部删除，二级视图切换改由侧边栏承担。
4. **面包屑 → 内容区定位条**：删除 `<Breadcrumb>`，改为 `data-testid="content-locator"`（板块名 · 副标题 › 视图名 [› 单号]）。
5. **默认落点**：`#/budget/annual`。无 hash / `#/` / `#/home` 均重定向至此；`#/home` 首访一次性提示「总览页已下线」。

## B. 侧边栏结构（三级三段）

- 品牌区（64）：`ApartmentOutlined` + 平台名 / 英文副标；折叠态仅图标。
- 目录区（flex:1，滚动）：3 个一级板块（40px，可折叠 `aria-expanded`）+ 9 个二级视图（36px，选中态 `brandBg` + 左侧 3px `brand` 指示条 + `brand` 文字）。
- 折叠触发器（48）：展开态「« 收起」，折叠态仅 `MenuUnfoldOutlined`。

## D. 令牌与持久化

- 新增令牌（`theme.js`，仅追加）：`navActiveBar`（3px 品牌色指示条）、`siderWidth` 224、`siderCollapsedWidth` 64。
- 折叠态持久化：`localStorage['dkt.sider.collapsed'] = 'true' | 'false'`（初始化读取，缺失默认 `false`）。
- 零 hex：侧边栏全部颜色经 `useT()` 派生，暗色主题自动跟随。
