# v0.5 年度预算计划 · 编制口径与版本模型修订

> 变更缘由：业务方明确了两个编制项的口径 —— ① BP 只需「已提交」＋版本记录；
> ② 需求清单的费用版本管理针对**整份清单**，不做逐条版本管理。
> 本轮只改编制口径与版本模型，不动 `calc.js` 中与计费/消耗相关的既有口径。

## 一、编制项：4 项 → 3 项

| 旧 | 新 |
|---|---|
| ① 年度 BP | ① 年度 BP |
| ② 需求清单 | ② **需求清单及费用预估**（合并） |
| ③ 总项目费用 | —（并入 ②，不再独立成项） |
| ④ 系统运维预算 | ③ 系统运维预算（口径不变，仍为 Digital 出具 → 业务复核确认） |

「总项目费用」= 需求清单**当前版本**的费用合计，因此不再单独维护状态。
主表「编制完整度」分母仍为 3（BP / 清单版本 / 运维预算）。

## 二、① 年度 BP：只有「已提交」

- 状态集合：`已提交` / `未提交`，**不再有** 归档、复核、编制中、未启动。
- 一次「提交 / 更新」= 提交文档或文档链接 ＋ 填写该版本基本信息（变更说明必填）。
- 只记录三件事：**版本号 · 更新时间 · 本次变更信息**（外加操作人）。
- 版本号由系统按次版本号自动递增（无历史 → `V1.0`），
  实现见 `calc.nextMinorVersion()`；每次提交同时写入 `bpVersions`。
- 数据：`BP_RECORDS`（每部门一条 = 当前生效版本）＋ 新增 `BP_VERSIONS`（版本变更记录）。
  未提交的部门不产生任何版本记录。

## 三、② 需求清单及费用预估：整份清单为一个版本

状态机：

```
（无版本）──业务一次性录完整份清单并「提交」──▶ 待评估费用（尚无版本号）
     ▲                                              │
     │                               Digital 逐条给出项目预算费用
     │                                      并「完成评估」
     │                                              ▼
     └──业务再次整体「提交」──────────────── 已确认（得号 V1.0）
           （新版本重新回到待评估费用，        │
             旧版本的核定费用被清空重估）       └─ 后续整体变更 → V1.1 → V1.2 …
```

- **版本单位 = 完整清单 + 完整费用预估**，不做逐条需求的版本管理。
- 首个确认版本为 `V1.0`，之后每次整体变更递增次版本号。
- 「已确认」版本中的条目费用**只读**（体现不逐条管理版本）；「待评估费用」阶段
  Digital 可在清单表内逐条录入「项目预算费用」。
- 确认时未手工核定的条目按业务预估计入，保证版本内一定是**完整费用预估**。
- 数据：
  - 新增 `DEMAND_VERSIONS`：`{ version(null=待评估) | status | count | totalAmount | submittedAt | confirmedAt | submitter | evaluator | changeNote }`
  - `demands` 新增 `evalAmount`（Digital 核定金额，元；`null` = 未核定）
  - `demands.status` 降级为**条目级描述字段**，不再承担版本状态职责

## 四、操作记录（planActivities）

- 编制项动作收敛：`BP: 提交/更新/催办`、`DEMAND: 提交/完成评估`、`OPS: 出具/复核确认/退回`。
- 删除 `PROJECT` 编制项及其动作；删除 `BP` 的「归档」动作。
- 每条记录新增 `version` 字段（版本号，可为 null）。

## 五、界面变更

- 主表列：`业务部门 | ① 年度 BP | ② 需求清单及费用预估 | ③ 系统运维预算 | 编制完整度 | 操作`（6 列，原 7 列）。
- 新增 `ProjectPanel` 下线，改为注释占位；相关口径说明收口到「需求清单」抽屉与「预算消耗」视图。
- BP 抽屉：`当前版本` Descriptive + **版本变更记录表**（版本号 / 更新时间 / 变更信息 / 操作人）。
- 需求清单抽屉：4 张版本状态卡 + 可逐条录入核定费用的清单表 + **版本记录表** + 操作留痕。
- 新增 `data-testid`：`budget-bp-versions`、`budget-demand-versions`、`budget-demand-table`、
  `demand-eval-{需求编号}`；移除 `budget-annual-cell-project-{部门}`、`budget-annual-project-drawer`。
- TraceChain ① 节点标签由「BP归档」改为「**BP提交**」（归档概念已不存在）。
